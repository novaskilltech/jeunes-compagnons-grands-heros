# Jeunes Compagnons, Grands Héros

Site de partage gratuit du livre commenté, publié par l’Institut de l’Excellence.

Projet Vercel : importer ce dépôt et lancer `npm run build` avec le répertoire `dist` comme sortie.

Le site présente huit biographies de compagnons du Prophète ﷺ, les commentaires de l’édition et une version PDF librement accessible.
